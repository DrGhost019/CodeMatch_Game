# Code Match

Two-player memory game built with Next.js (App Router).

    npm install
    npm run build
    npm start          # serves on 192.168.100.1:3000

Open http://192.168.100.1:3000 on both devices (same Wi-Fi / hotspot).
Card icons live in `lib/icons.ts` (one SVG fragment per icon id). Room state is in memory: run a single server process.
